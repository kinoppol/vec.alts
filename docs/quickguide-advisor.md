# หน้า 1 — งานประจำวัน

## เข้าสู่ระบบ

**……………………………………………** *(ผู้จัดทำเติมที่อยู่เว็บ)*

กด **เข้าสู่ระบบ** → เลือก **บุคลากร** → กรอกอีเมลและรหัสผ่าน

> **ครูที่โอนข้อมูลมาจากระบบ RMS** ให้ใช้ **เลขประจำตัวประชาชน 13 หลัก** เป็นชื่อผู้ใช้
> (ระบบ RMS ใช้เลขบัตรเป็นรหัสบุคลากร) หากไม่มีอีเมลในระบบ ให้ใช้ช่องทางนี้

`[ภาพที่ 1]` — หน้าเข้าสู่ระบบสำหรับบุคลากร

---

## หน้าจอหลัก: ข้อมูลนักศึกษาในความดูแล

แสดง **ทั้งนักศึกษาปัจจุบันและศิษย์เก่า** ที่อยู่ในความดูแลของท่าน

**การ์ดสรุป 4 ใบด้านบน**

| การ์ด | ความหมาย |
| --- | --- |
| ในความดูแลทั้งหมด | จำนวนรวมทั้งสองกลุ่ม |
| กำลังศึกษา | นักศึกษาปัจจุบัน |
| ศิษย์เก่า | ผู้ที่สำเร็จการศึกษาแล้ว |
| ศิษย์เก่าที่รอติดตาม | **ตัวเลขที่ต้องทำให้เป็นศูนย์** |

`[ภาพที่ 2]` — หน้าข้อมูลนักศึกษาในความดูแล พร้อมการ์ดสรุปและตัวกรอง

**เครื่องมือค้นหา:** ช่องค้นหา (ชื่อ/รหัส) · ตัวกรองประเภท · ตัวกรองสถานะการสำรวจ ·
ตัวกรองสาขา · เลือกจำนวนรายการต่อหน้า (10 / 25 / 50 / 100)

---

## งานที่ 1 — ปรับปรุงข้อมูลนักศึกษาปัจจุบัน

**ทำได้ทุกเมื่อ ไม่ต้องรอถึงกำหนดสำรวจ**

1. กดปุ่ม **ปรับปรุงข้อมูล** ที่แถวของนักศึกษา
2. แก้ไข **เบอร์โทรศัพท์ อีเมล Line ID ที่อยู่**
3. เลือก **แผนหลังสำเร็จการศึกษา** — ทำงาน / ศึกษาต่อ / อาชีพอิสระ / ยังไม่แน่ใจ
4. บันทึก **สถานะการติดต่อ** หากติดต่อยาก
5. กด **บันทึกข้อมูล**

`[ภาพที่ 3]` — หน้าปรับปรุงข้อมูลนักศึกษา

---

## งานที่ 2 — กรอกแบบสำรวจแทนศิษย์เก่า

ใช้เมื่อโทรติดต่อศิษย์เก่าได้ แต่เขาไม่สะดวกกรอกเอง

1. กรองรายชื่อด้วย **สถานะการสำรวจ → รอติดตาม**
2. กดปุ่ม **กรอกแทน** ที่แถวของศิษย์เก่า
3. กรอกข้อมูลติดต่อและเลือก **สถานะปัจจุบัน** 1 ข้อจาก 6 แบบ
4. บันทึก **สถานะการติดต่อ** — ติดต่อได้ / ติดต่อยาก / ติดต่อไม่ได้
5. กด **บันทึกและส่งข้อมูล**

`[ภาพที่ 4]` — หน้ากรอกแทนศิษย์เก่า

> ปุ่ม **กรอกแทน** จะไม่ขึ้นกับนักศึกษาปัจจุบัน เพราะแบบสำรวจภาวะการมีงานทำ
> มีไว้สำหรับผู้ที่สำเร็จการศึกษาแล้วเท่านั้น

# หน้า 2 — รายละเอียดและข้อควรรู้

## สถานะปัจจุบัน 6 แบบ และข้อมูลที่ต้องถามเพิ่ม

| สถานะ | ต้องถามเพิ่ม |
| --- | --- |
| 💼 มีงานทำ (ตรงสาขา) | ชื่อที่ทำงาน · ตำแหน่ง · เงินเดือน · จังหวัด |
| 🧰 มีงานทำ (ไม่ตรงสาขา) | เหมือนข้างต้น |
| 🚀 ประกอบอาชีพอิสระ | เหมือนข้างต้น |
| 🎓 ศึกษาต่อ | สถานศึกษา · ระดับ · สาขาวิชา |
| 🔎 ว่างงาน / กำลังหางาน | หมายเหตุ เช่น กำลังหางานสายใด |
| 🪖 เกณฑ์ทหาร | หมายเหตุ |

---

## ข้อมูลที่แก้ไขได้ และแก้ไม่ได้

**แก้ไขได้ที่ระบบนี้**
เบอร์โทรศัพท์ · อีเมล · Line ID · ที่อยู่ · แผนหลังจบ · สถานะและหมายเหตุการติดต่อ

> เมื่อท่านแก้ข้อมูลติดต่อแล้ว ระบบจะ **ยึดค่าที่ท่านบันทึกไว้**
> และจะไม่ถูกเขียนทับเมื่อโอนข้อมูลจากระบบ RMS ครั้งต่อไป

**แก้ไขไม่ได้ (ข้อมูลทะเบียน)**
รหัสนักศึกษา · ชื่อ-นามสกุล · ระดับชั้น · สาขาวิชา · กลุ่มเรียน · GPAX · ปีที่เข้าศึกษา

> **หากข้อมูลทะเบียนไม่ถูกต้อง** ให้แจ้งงานทะเบียนแก้ไขที่ **ระบบ ศธ.02 ออนไลน์**
> ซึ่งเป็นต้นทางของข้อมูลในระบบ RMS แล้วจึงโอนข้อมูลเข้าระบบนี้ใหม่
>
> **ควรแจ้งงานทะเบียนแก้ที่ ศธ.02 ด้วยเสมอ** แม้จะแก้ในระบบนี้ไปแล้ว
> เพื่อให้ข้อมูลตรงกันทุกระบบ

## สรุปกลุ่ม

เมนู **สรุปกลุ่ม** แสดงสัดส่วนสถานะของศิษย์เก่าในความดูแล ใช้ดูภาพรวมว่ากลุ่มของท่าน
มีผู้มีงานทำ ศึกษาต่อ หรือว่างงานกี่คน

`[ภาพที่ 5]` — หน้าสรุปกลุ่ม

---

## ครูที่ปรึกษาของแต่ละกลุ่มมาจากไหน

ระบบผูกครูที่ปรึกษาให้อัตโนมัติ โดยจับคู่จาก **เลขประจำตัวประชาชน** ของครู
ที่ระบุไว้ในระบบ RMS กับบัญชีผู้ใช้ในระบบนี้

**หากรายชื่อนักศึกษาในความดูแลไม่ถูกต้อง** ให้แจ้งผู้ดูแลระบบ
เพื่อตรวจสอบข้อมูลกลุ่มเรียนในระบบ RMS แล้วโอนข้อมูลใหม่

---
