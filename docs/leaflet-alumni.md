## ทำไมต้องกรอก

ข้อมูลของท่านช่วยให้วิทยาลัยพัฒนาการเรียนการสอนให้ตรงกับความต้องการของตลาดแรงงาน
และใช้รายงานต่อหน่วยงานต้นสังกัด **ใช้เวลาไม่เกิน 3 นาที**

## 3 ขั้นตอนง่าย ๆ

### ① เข้าเว็บไซต์

**……………………………………………**
*(ผู้จัดทำเติมที่อยู่เว็บ หรือใส่ QR Code)*

`[ภาพที่ 1]` — QR Code ของเว็บไซต์ระบบ (สร้างจากที่อยู่เว็บ วางขนาดประมาณ 3x3 ซม.)

### ② เข้าสู่ระบบ

กดปุ่ม **เข้าสู่ระบบ** → เลือก **ศิษย์เก่า / นักศึกษา** แล้วกรอก

| ช่อง | ใส่อะไร |
| --- | --- |
| รหัสนักศึกษา | **รหัสเดิมตอนเรียน** |
| รหัสผ่าน | **เลขบัตรประชาชน 13 หลัก** (ไม่ต้องใส่ขีด) |

`[ภาพที่ 2]` — หน้าจอเข้าสู่ระบบของศิษย์เก่า

### ③ กรอกข้อมูลแล้วกดบันทึก

1. ตรวจสอบ **เบอร์โทรศัพท์ / อีเมล / Line ID / ที่อยู่** ให้เป็นปัจจุบัน
2. เลือก **สถานะปัจจุบัน** 1 ข้อ
3. กรอกรายละเอียดที่ระบบถามเพิ่ม
4. กด **บันทึกและส่งข้อมูล**

`[ภาพที่ 3]` — หน้าแบบสำรวจ แสดงตัวเลือกสถานะทั้ง 6 แบบ

## คำถามที่พบบ่อย

**เข้าระบบไม่ได้**
ตรวจว่าใช้ **รหัสนักศึกษาเดิมตอนเรียน** และเลขบัตร **13 หลักติดกัน** ไม่ต้องเว้นวรรคหรือใส่ขีด
หากยังไม่ได้ ติดต่อครูที่ปรึกษาหรืองานทะเบียน

**กรอกยังไม่เสร็จ ต้องรีบไปทำธุระ**
กด **บันทึกร่าง** ไว้ก่อน แล้วกลับมากรอกต่อได้ *(ยังไม่นับว่าส่งข้อมูล ต้องกลับมากดส่งอีกครั้ง)*

**กรอกส่งไปแล้ว แก้ไขได้ไหม**
ได้ เข้าไปแก้แล้วกดบันทึกใหม่ได้ตลอด

**ข้อมูลของฉันจะเป็นความลับหรือไม่**
เลขบัตรประชาชนถูกเก็บแบบเข้ารหัส ไม่มีใครอ่านย้อนกลับได้
ส่วน **เงินเดือนจะไม่แสดงเป็นรายบุคคล** ในรายงานใด ๆ แต่สรุปเป็นช่วงเท่านั้น
